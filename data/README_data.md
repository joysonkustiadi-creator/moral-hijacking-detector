# 📂 Dataset Instructions

The datasets used in this project are publicly available on Kaggle.
They are **not included** in this repository due to file size and licensing.

## Download Instructions

### 1. Tweet Emotions Dataset
- **Source:** Kaggle:  Emotion Detection from Text
- **Author:** Pashupati Gupta
- **Link:** https://www.kaggle.com/datasets/pashupatigupta/emotion-detection-from-text
- **File needed:** `tweet_emotions.csv`

### 2. Propaganda Dataset
- **Source:** Kaggle: Propaganda Detection (SemEval/NLP4IF)
- **Author:** Mahdi Mashayekhi
- **Link:** https://www.kaggle.com/datasets/mahdimashayekhi/propaganda-detection
- **File needed:** `propaganda_dataset.csv`

## Placement

After downloading, place both files in this `data/` folder:

```
data/
├── tweet_emotions.csv
├── propaganda_dataset.csv
└── README_data.md   ← this file
```

Then run `scopus_final.ipynb` from the root directory.
